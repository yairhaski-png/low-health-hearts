# קשר

אפליקציית PWA (Progressive Web App) אישית - תורה, כושר ונקודות. בלי App Store, בלי אפל, בלי אישורים.

## מה זה בעצם עשיתי?

בנוי כאתר סטטי רגיל (HTML/CSS/JS, בלי שרת, בלי בילד). זה בדיוק הרעיון שהצעת: אתר שיושב על "הוסף למסך הבית" באייפון, ונפתח כמו אפליקציה - במסך מלא, בלי סרגל הכתובת של ספארי, עם אייקון משלו.

## למה זה עובד ומה החסרונות (התשובה לשאלה שלך)

**כן, זה עובד מצוין** ובדיוק בשביל זה קיים תקן ה-PWA. זה בדיוק מה שאתה מתאר: "אתר ששם אותו על מסך הבית ולוחצים ונפתח".

**יתרונות:**
- אפס תלות באפל - אין App Store, אין ריוויו, אין דמי מפתח (99$ בשנה), אין דחייה על תוכן.
- עדכונים מיידיים - משנים קובץ, פותחים מחדש, זהו. אין המתנה לאישור.
- עובד מהיום להיום גם בלי אינטרנט (Service Worker שומר קאש).
- אפשר להתקין רק לעצמך, בלי לפרסם לאף אחד.

**חסרונות שכדאי לדעת:**
1. **אין גישה מלאה ל-HealthKit / חיישני תנועה** - לא תוכל למדוד שכיבות שמיכה אוטומטית עם המצלמה/סנסורים כמו אפליקציה נייטיב. כרגע זה סימון ידני ("סימנתי שביצעתי").
2. **מגבלת אחסון** - אם לא פותחים את האפליקציה הרבה זמן (בערך חודש), iOS יכול לנקות את הנתונים השמורים (localStorage). לרוב זה לא קורה אם פותחים פעם בכמה ימים, אבל כדאי לדעת - **זה לא מגבה לענן**.
3. **בלי Push Notifications אמיתי** - מ-iOS 16.4 יש תמיכה חלקית בהתראות ל-PWA שמותקנות במסך הבית, אבל זה פחות אמין ופחות עשיר מאפליקציה רגילה.
4. **בלי ווידג'טים, בלי Siri Shortcuts, בלי מסך נעילה** - כל הפיצ'רים ה"עמוקים" של iOS לא זמינים.
5. **צריך אחסון (hosting) עם HTTPS** - אי אפשר סתם לפתוח קובץ מהמחשב, ה-Service Worker (שנותן את חוויית ה"אפליקציה") דורש אתר אמיתי. הפתרון: GitHub Pages / Netlify / Vercel - כולם בחינם, 5 דקות הקמה.

**מסקנה:** בשביל שימוש אישי (אתה בלבד, בלי לשתף עם חברים) - זו האופציה הכי טובה. אם בעתיד תרצה לשתף עם עוד אנשים, כל אחד יצטרך לבצע "הוסף למסך הבית" בעצמו (זה לא הפצה אוטומטית) - אבל זה עדיין בלי אפל.

## איך מתקינים באייפון

1. מעלים את הקבצים לאחסון חינמי (למשל GitHub Pages - ראה למטה).
2. פותחים את הכתובת ב-**ספארי** באייפון (חייב ספארי, לא כרום).
3. לוחצים על כפתור השיתוף (הריבוע עם החץ) ↦ "הוסף למסך הבית" (Add to Home Screen).
4. האייקון החדש מופיע במסך הבית - לחיצה עליו פותחת את האפליקציה במסך מלא, בלי כלום מספארי.

## איך מפרסמים בחינם (GitHub Pages)

1. דוחפים (push) את התיקייה הזו ל-GitHub (כבר בוצע בברנץ' הזה).
2. ב-repo, נכנסים ל- Settings → Pages.
3. תחת "Source" בוחרים את הברנץ' הרלוונטי ותיקיית ה-root.
4. אחרי דקה-שתיים תקבל כתובת כמו `https://<username>.github.io/<repo>/` - זו הכתובת שפותחים בספארי באייפון.

## מבנה הפרויקט

```
index.html              עמוד האפליקציה (3 לשוניות: לובי, נקודות, חנות)
css/style.css           עיצוב שחור-זהב, RTL
js/app.js               כל הלוגיקה - נקודות, אתגרים, חנות, שמירה ב-localStorage
manifest.webmanifest    הגדרות PWA (שם, אייקון, מצב מסך מלא)
sw.js                   Service Worker לעבודה אופליין
icons/                  אייקונים למסך הבית
```

## מה יש בגרסה הראשונית

**לובי** - נקודות נוכחיות, רצף ימים, יעד קרוב (ניתן לעריכה), מה נשאר לעשות היום, ציטוט מוטיבציה יומי, וסיכום (בוצע היום, סה"כ נקודות, פריטים שנקנו, ימי רצף).

**נקודות ואתגרים** - רשימת אתגרים (לימוד תורה, תפילה, שכיבות שמיכה, הליכה/ריצה, אימון כושר) - לחיצה מסמנת כבוצע ומזכה בנקודות. אפשר להוסיף/למחוק אתגרים משלך.

**חנות** - קונים פרסים בנקודות שצברת (יום חופש, פינוק, סרט, ספר וכו'). אפשר להוסיף/למחוק פריטים, ורואים היסטוריית קניות.

כל הנתונים נשמרים על המכשיר שלך בלבד (localStorage) - אין שרת, אין חשבון, אין מעקב.

## מה כדאי לשפר בהמשך (לא בגרסה הזו)

- גיבוי לענן (כדי לא לאבד נתונים אם ה-iOS מנקה אחסון)
- לוח שנה / היסטוריית ימים
- התראות תזכורת יומיות (Push, כשיהיה נוח)
